# Capturas del informe

Guarda aquí las capturas que muestra el README principal, con estos nombres:

| Fichero | Contenido |
|---|---|
| `01-resumen.png` | Página Resumen completa (1280 × 720 px) |
| `02-estacionalidad.png` | Página Estacionalidad |
| `03-benchmark.png` | Página Benchmark (España Verde) |
| `04-tooltip.png` | Información sobre herramientas "Detalle del mes" sobre el gráfico de tendencia |
| `demo.gif` | (Opcional) Recorrido de 10–20 s por las páginas |

Recomendaciones:

- Exporta a 1280 × 720 px o al doble (2560 × 1440) para pantallas de alta densidad.
- Selecciona Gijón y el último año completo antes de capturar.
- Comprime los PNG (por ejemplo con TinyPNG o `oxipng`) para que el README cargue rápido.
- Después, en el `README.md` raíz, sustituye el wireframe y descomenta las líneas de imagen.
